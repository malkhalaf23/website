# Cut Tracker

A complete React + Tailwind app for managing a 16-week cut/recomp plan with localStorage persistence.

## Features
- Dashboard with current status, compliance, and recommendations
- Editable macro targets and actual intake tracking
- Meal planner with default schedule and meal prep raw/cooked meat notes
- Daily training and recovery logs
- Weight tracker, weekly average calculations, and Recharts visualizations
- Waist tracker
- Goal projection and target-vs-actual trend comparison
- Compliance tracker
- Inventory tracker for meal prep bags and staple foods
- Settings page for editing the cut profile
- Light/dark mode persisted in localStorage

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Dependencies
